## 2. 클로드가 잘못 만든 것과 알아챈 방법 (README 7.1절 6항 후보)

### 2.1 AI 시간 제한이 실제로는 늦게 끊김
- 처음 만든 `call_openrouter`는 제한 시간이 지나면 메인 스레드에서 `resp.close()`를 불러 연결을 끊었다.
- 가짜 서버로 "1초마다 유지 신호만 보내는 응답"을 시험하니, 결과는 "시간 초과"로 나왔지만 **제한 3초인데 실제로는 20초 뒤에** 돌아왔다(`tests/test_ai_http.py::test_total_timeout_cuts`가 `took < 4.5` 검사에서 실패).
- 원인: 다른 스레드가 읽는 중인 스트리밍 응답을 닫는 호출이 읽기가 끝날 때까지 막혔다. 이대로면 120초 제한이 지켜지지 않아 3장 "AI 응답이 늦을 때"의 어려운 해결이 되지 않는다.
- 고침: 연결 닫기를 별도 스레드에서 하고(소켓 `shutdown`), 메인은 바로 다음 모델로 넘어가게 했다. 다시 시험하니 3.0초에 끊겼다.

### 2.3 무료가 아니게 된 모델을 1차로 고름
- 클로드가 10/19에 웹 검색으로 고른 1차 모델 `nvidia/nemotron-3-super-120b-a12b:free`(공고 예시와 같은 모델)와 3차 `qwen/qwen3.8-27b:free`가 10/31 실제 호출에서 `HTTP 404: 무료로 제공되지 않음`을 냄.
- 알아챈 방법: 집 컴퓨터에서 실제 키로 AI 배정을 눌러 본 화면(`img/ai-fallback.png`)과 `test_models.py` 결과.
- 고침: 실제로 통과한 모델로 1~3차를 다시 정함(`tfapp/config.py`).

### 2.2 불가능한 배정을 가능하다고 본 시험 코드
- 클로드가 만든 시험 `test_solve_eight_unassigned_four_empty_teams_fast`는 "기획자를 맡을 수 있는 학생이 2명뿐인 8명"을 빈 팀 4개에 배정할 수 있다고 기대했다.
- 앱의 백트래킹이 "배정 없음"을 내서 시험이 실패했고, 따져 보니 팀 4개에 기획자가 4명 필요하므로 **시험의 기대가 틀린 것**이었다(앱이 옳았음).
- 고침: 시험을 둘로 나눔. 기획자 가능 4명이면 배정됨 / 2명이면 "기획자가 없는 팀이 4개인데…" 이유와 함께 배정 없음.
